- `hangar.shell.ops` finds more test runs (KAN-279): inside loops and conditions (`for f in a; do pytest $f; done`),
  past a wrapper flag's value (`uv run --project svc pytest`) and in test or CI scripts run by `sh`, `bash` or their
  path (`bash scripts/ci/verify.sh`). A runner asked only for `--version`, `--help`, `--collect-only` or its test list
  is no longer a test run. Behavior specs, digests and step labels keyed on `test` see the difference.
