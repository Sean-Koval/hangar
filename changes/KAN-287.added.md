- **What a command wrote and ran** (KAN-287, [docs/api/shell-facts.md](docs/api/shell-facts.md)). A shell call's
  event now carries `writes`, `runs` and `probe`, read from the whole command before its 200-character preview is
  clipped: the files it writes (redirects, `tee`, `sed -i`, `cp`/`mv` targets, a diff fed to `git apply`, Python
  writes in a heredoc), the programs it runs (`git status`, `python -m pytest`, past `uv run` and `timeout`) and
  whether its test runs only asked for a version, help or test list. A file tool's event carries `writes`. Trace
  spans get `hangar.shell.writes`, `.runs` and `.probe`; older events are read from their preview.
