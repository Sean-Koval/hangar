- **Claude Code on Vertex AI** (KAN-291). A Google service-account key stored for Claude Code
  (`hangar cred add NAME --team --harness claude-code --kind generic --file key.json`) runs Claude Code on Vertex AI,
  billed to the key's project or the environment's `ANTHROPIC_VERTEX_PROJECT_ID`, in `CLOUD_ML_REGION` (default
  `global`). It is an API-key-class login, so jobs take it. A sandbox with it, or whose environment sets
  `CLAUDE_CODE_USE_VERTEX`, may reach Vertex AI's endpoints and nothing more of Google's. Adding a Vertex key
  doesn't move existing work: beside another Claude Code login it is used only where an environment names it. An
  environment that names both is warned; a `model_gateway: record` sandbox keeps the gateway.
  `hangar doctor`'s `claude on vertex` line checks each key with one call that reaches no model. Vertex model ids
  are priced in `/api/usage`. [Claude Code on Vertex AI](docs/team/vertex.md).
