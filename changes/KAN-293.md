- A Jira-started job gets the Confluence pages its ticket links to (KAN-293): remote links, the description and
  comments by linked people. hangar reads them on the control plane with the Jira site's token, never off that site,
  and only when the person who started the job can read them too. They become untrusted `confluence-<id>-<slug>.md`
  context files: 5 pages, 50,000 bytes each, children listed, not read. `jira-<key>.md` says which file each link
  became or why it wasn't read. Search in configured spaces is off by default. Data Center links are listed, not
  read. See docs/intake/confluence.md.
