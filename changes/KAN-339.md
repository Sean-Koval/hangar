- A job whose PR fails to open now says why (KAN-339): a GitHub error keeps its `errors[]` reasons (`code`, `field`,
  `message`), and the job records them in the new `result.pr_error`, which `hangar job list` shows in place of the PR
  URL. A PR body over 60,000 characters is cut, with a note pointing at the job's RESULT.md, so GitHub's 65,536 limit
  no longer stops the PR. A 422 saying a PR already exists for the branch adopts that PR.
