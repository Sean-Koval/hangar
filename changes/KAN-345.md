- **`hangar trace import --all` imports a whole Claude Code projects folder** (KAN-345), one directory per session,
  with `--since` and `--repo` to narrow it. `index.json` makes it incremental: a second run writes nothing and says
  so, and a grown session is imported again. A session whose branch starts with a Jira key (`KAN-35-apply-atomic`)
  carries `hangar.ticket.key`, as hangar-run sessions do, with `hangar.git.branch` and `hangar.repo.dir`.
  [A whole folder](docs/api/trace-import.md#a-whole-folder-again-and-again).
