- **`hangar doctor --local` checks a laptop before any server** (KAN-351), with no login and no network. It covers
  Python and uv, which container runtime answers (Docker Desktop's licence is a `!`), the port, and a TLS-inspecting
  proxy without `HANGAR_EXTRA_CA_BUNDLE`. It also checks reachability of github.com and the harnesses' hosts, whether
  jobs would find an API key, and that `hangar trace import` works offline. `hangar up` runs it first and stops on a
  ✗. [Before a server](docs/team/doctor.md#before-a-server-hangar-doctor-local).
