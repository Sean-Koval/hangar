- **`hangar doctor` compares the audit table with the audit bucket** (KAN-541). With `HANGAR_AUDIT_BUCKET` set to the
  locked audit bucket's view, a new `audit bucket` line reads the bucket's audit lines of the last 30 days. It fails
  when the table stops short of the newest `seq`, holds an entry with another `hash`, or the bucket holds one entry
  twice with different links: rows cut from the end, a reset table, or a restore from an older backup written past.
  Unset or unreadable, the line says "not run", never ok. The Terraform audit export grants hangar
  `roles/logging.viewAccessor` on that one view and outputs `audit_view`; `deploy/gke/up.sh` sets the variable.
  [Doctor's comparison](docs/security/audit.md#doctors-comparison).
