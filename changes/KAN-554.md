- **Break-glass needs two people, not two tokens** (KAN-554). hangar now records who could hold each token: its
  person, plus whoever held the token that minted it. Confirming break-glass needs a token no one could hold together
  with the starting token, so an admin can no longer confirm with a token they minted for another admin. Confirm
  with your own single sign-on (`hangar login --sso`) or a token minted on the server's host (`hangar token create --person
  <you>`); tokens minted before this release can't start or confirm break-glass.
  [Break-glass](docs/runbooks/break-glass-tower.md#break-glass).
