- **The driver sidecar's probe and the local runner keep the agent out** (KAN-555). The sidecar probe runs
  `/bin/sh`, never a `sh` found through the agent's `PATH`, so a planted `~/.local/bin/sh` can't answer it. The
  relay starts only with a `python3` from a system directory whose library path and links the agent can't change,
  and the probe's user ids must match the pod's spec, which may not run the agent as root. Sandboxes probed before
  are probed again. `hangar env local` gives its internal network's bridge no IPv4 address and the agent no IPv6 or
  raw sockets, so the agent can't reach services on your computer; `check` fails if anything there answers or
  refuses.
  On Docker Desktop, `check` also tries Desktop's address for the Mac or Windows host. A probe whose `python3`
  lists no library directories is refused.
